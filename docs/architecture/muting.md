# Muting

A user may mute a text channel, DM, group DM, or channel a plugin shows (whose plugin's notices a mute silences; see Plugins) for themself alone (`app::channel_mute`, table `channel_mute`: the user and the channel, both cascading, and `until`, `NULL` for a mute that lasts until lifted). `PUT /channels/{channel}/mutes/@me` with `durationSeconds` (absent or `null` for indefinitely, at most a year) mutes it, `201` when it was not muted and `200` when it replaced a mute in force; `DELETE` on the same path lifts it. Each change is published to the user's own subject as the custom `channelMuteChanged` event; a mute that runs out ends on each device by its own clock, with no event, and a row whose `until` has passed is simply not read back. Community reads and the DM list sideload the caller's mutes in force with `include=mutes`, as `included.channelMutes`. A muted channel keeps its read position, so what arrived meanwhile is unread once the mute ends; clients dim it and never show it as unread in their lists. A thread's messages count as its parent's for muting. A muted channel notifies of nothing, tags included, and wakes no phone (see Notifications).
