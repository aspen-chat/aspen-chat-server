# Reactions

A reaction is a row of `react` (the emoji, the user, the message, and when). Only a single emoji is accepted, and it is stored, compared, and named in records and events in the fully qualified form Unicode lists for it (`app::react::canonical_emoji`), so `❤` and `❤️` are one reaction. Adding and removing one is `PUT` and `DELETE /messages/{message}/reactions/{emoji}/@me` (`app::react`). Message reads sideload reactions in brief with `include=reactions`, one `ReactionSummary` per message and emoji: the count, whether the caller reacted, and the first four to react, earliest first, each message's emoji in the order first used on it; it stays small however popular a message is. Everyone who reacted with an emoji is `GET /messages/{message}/reactions/{emoji}`, user records earliest first, paged with `after` (the last user of the previous page) and `limit` (at most 100). The index `react_by_message` serves both, and both leave out anyone the caller blocked. A deleted message takes no reaction and lists no reactors: both answer `404`, as reading it would.
