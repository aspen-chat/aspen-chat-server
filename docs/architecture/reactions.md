# Reactions

A reaction is a row of `react` (the emoji, the user, the message, and when). Only a single emoji is accepted, and it is stored, compared, and named in records and events in the fully qualified form Unicode lists for it (`app::react::canonical_emoji`), so `❤` and `❤️` are one reaction. Adding and removing one is `PUT` and `DELETE /messages/{message}/reactions/{emoji}/@me` (`app::react`). A message carries at most 50 different emoji (`react::MAX_DISTINCT_PER_MESSAGE`): one more is refused with `reactTooManyDistinct`, checked under a lock on the message's row in the transaction that adds it, while adding to an emoji already there is always allowed. Message reads sideload reactions in brief with `include=reactions`, one `ReactionSummary` per message and emoji: the count, whether the caller reacted, and the first four to react, earliest first, each message's emoji in the order first used on it; it stays small however popular a message is. Everyone who reacted with an emoji is `GET /messages/{message}/reactions/{emoji}`, user records earliest first, paged with `after` (the last user of the previous page) and `limit` (at most 100). The index `react_by_message` serves both, and both leave out anyone the caller blocked. A deleted message takes no reaction and lists no reactors: both answer `404`, as reading it would.

The emoji someone reacts with most are `GET /users/@me/frequent-emoji` (`app::react::read_frequent`), which the apps' quick reactions offer: first those used in the past 90 days (`FREQUENT_RECENT_DAYS`), most used there first, then the rest by how often they were used, each tie going to the one used last, at most 20 (`MAX_FREQUENT`; 5 unless `limit` says). They are counted from the caller's own rows of `react`, read newest first along `react_by_author` (`author`, `timestamp`, carrying `emoji` and `custom_emoji`) and stopping at their latest 10,000 (`FREQUENT_WINDOW`), so the read is an index-only scan whose cost stops growing with the reactions someone has made; nothing else is stored, and a reaction taken back no longer counts, while one on a message since deleted still does, since deleting a message keeps its reactions. `community` names the community the emoji are wanted for: its own custom emoji count among them, and no other's, since a custom emoji reacts only where it is defined; without it (a DM) only Unicode emoji count. Only the caller reads their own: another user's answers `403` `forbidden`. It tells no one anything they did not do themselves, so no change to anyone's access touches it, and no event announces it; the apps read it again after each of the caller's own `react` events.
