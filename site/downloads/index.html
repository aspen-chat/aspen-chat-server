Download Aspen Chat clients

  • Linux

    • Flatpak

      Any distribution. Updates with flatpak update.

      Download aspen.flatpakref, then open it with your software center, or run flatpak install aspen.flatpakref.

    • Debian and Ubuntu

      Installing the package adds Aspen's repository, so Aspen updates along with the rest of the system.

      Download the .deb

    • Fedora and openSUSE

      Installing the package adds Aspen's repository, so Aspen updates along with the rest of the system.

      Download the .rpm

    • Arch Linux

      Install aspen-bin from the AUR with your AUR helper.

    • Archive

      Any distribution. It does not update; download the next release yourself.

      Download the .tar.gz
